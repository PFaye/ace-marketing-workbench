## 结构
- `server/server.js`：零依赖 Node 后端：静态页、`/api/state`、`/api/collections/*`、`/api/llm/v1/chat/completions`（模型代理）、`/api/monitor/*`（告警、日报、推送）、`/api/setup`（首次向导）、定时任务。
- `server/lib/`：store（JSON 文件）、llm（OpenAI 兼容 / Anthropic）、monitor（公式与规则）、connectors（HTTP 接口、官方平台预留）、mapping（表头识别）、seed。
- `build/parts/`：1 样式 → 2 页面 → 3 示例数据 → 4 核心（数据仓库、AI 层、登录） → 4b 公式与图表 → 5 全案 → 6 内容工厂 → 7 达人 → 8 数据接入 → 9 监测 → 10 洞察 → 10b 开始页（一键出全套） → 11 设置与启动 → 12 引导。
- v3.2 起**不再预装示例数据**：首次打开是空白起点（只有告警规则、连接器、设置）。示例由「开始」页折叠区的「载入示例数据」手动载入，带 `source: "示例"/"示例数据"` 标记，可一键清空；「设置」里「清空全部数据」在本地和服务端都可用（规则、连接器、模型设置保留）。
- 升级兼容：旧版本预装的示例在升级后第一次启动时自动清掉（服务端在 `server.js` 启动时按 `meta.v3` 标记做一次；浏览器本地按 `ace.db.meta.v >= 3` 做一次；更早版本的示例投放数据没有 source 标记，按「平台 + 计划名」指纹识别），用户自己生成或导入的内容保留。
- 开始页（`build/parts/10b_start.js` + `2_body.html` 开头 + `1_head.html` 末尾 v3.2 样式）：Hero（极光渐变 + 粒子星网 canvas + 渐变流光标题）→ 玻璃卡片里粘 Brief → 「一键出全套」→ 五节点流水线实时点亮、「AI 正在写」滚动行（来自 `4_core.js` 的 `aiLive` 总线）、新稿件卡片飞入、汇总数字卡。「把真实业务搬进来」清单折叠在最下面。
- 本地调试：`.claude/launch.json` 里有 `static`（纯前端）、`mock`（假模型，脚本在会话临时目录，丢了可以按 OpenAI 流式格式随手写一个）、`server`（用 `.node/bin/node` 跑后端）三个配置。

## 常见操作
- 忘记口令：Railway → Variables 加 `ADMIN_TOKEN=新口令`（环境变量优先于向导设置）。
- 换模型：登录后「设置」里改，或 Railway 加 `LLM_BASE / LLM_KEY / LLM_MODEL`。
- 载入 / 清空示例：登录后「开始」页最下面「把真实业务搬进来」折叠区；全部清空在「设置」。
