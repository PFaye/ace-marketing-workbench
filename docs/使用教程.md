# ACE 营销工作台 · 使用教程（一页）

整个流程五步，每步一个动作：**粘贴、点一下、拖进来**。第一次打开页面会自动进入这五步的手把手引导；左下角「重看引导」可重来，「完整流程」是这一页的文字版。

## 一张图看流程

```
Brief ──粘贴──▶ 全案策划 ──AI──▶ 项目设定（主张 / 核心信息 / 客户确认版）
                                      │
          ┌───────────────┬───────────┼───────────────┬──────────────┐
          ▼               ▼           ▼               ▼              ▼
      内容工厂        达人匹配      评论洞察        投放监测        日报推送
      批量出稿        一键组合      主题 / 负面      规则告警        飞书 / 企微
      审校导出        合作 Brief                     AI 日报
          ▲               ▲                           ▲
          └── 数据接入：拖入蒲公英 / 星图 / 投放后台导出的表 ──┘
```

项目设定是中枢，其他工具都读它。表格导入只进达人库和投放数据，和方案互不影响。

## 把业务搬进来（开始页）

左侧第一项「开始」是清单页：AI 状态一眼看到（管理员配好 Key 后所有人直接用），三步清单做完自动打勾：粘你的 Brief 生成、导入达人名单、导入投放日报，再填一次群机器人。登录后可一键「清空示例数据」。

## 五步

**1 定项目（全案策划）**
把客户 Brief 或一句话需求粘进去 → 点「生成全案」→ 五个环节依次出来。生成完成后「项目设定」自动填好传播主张。

客户改了方案，或根本不用 AI 的方案：打开「项目设定」→ 改主张、核心信息，或把客户确认的最终版粘进「客户确认版方案」→ 保存。之后内容、达人 Brief、洞察、日报都按这个版本。**不需要重新上传任何东西。**

**2 出内容（内容工厂）**
选类型（KOC 笔记 / 评论话术 / 社群话术 / 信息流 / 直播口播）和数量 → 点「开始批量生成」→ 稿件一条条出现 → 逐条改稿、点「标为已审校」→ 「导出 CSV」或「复制已审校」交给达人或运营。敏感词会自动标出，含广告法禁用词的稿件不会被批量标为已审校。

**3 选达人（数据接入 → 达人匹配）**
蒲公英 / 星图后台导出表格 → 在「数据接入」拖进去或直接粘贴 → 字段自动识别 → 「确认导入」。
到「达人匹配」填本轮预算 → 点「一键推荐组合」→ AI 评估每位达人并按预算自动勾选 → 手动增减 → 「为已选达人生成合作 Brief」→ 在表里改合作状态、填跟进日。

**4 盯投放（数据接入 → 投放监测）**
每天把投放后台导出的日报表拖进「数据接入」（导入到「投放日报」）→ 「投放监测」自动算告警 → 点「运行监测并生成日报」→ 「推送到群」。
在「自动推送」里填一次飞书 / 企微机器人并勾选自动，之后每天到点自己跑、自己推。

**5 看反馈（评论洞察）**
把评论区、客服记录粘进去 → 「分析评论」→ 主题、原话、负面预警、机会词 → 负面先回应，机会词写进下一批内容的视角里。

## 常见问题

- **改方案要重新上传吗？** 不用。方案不是文件，改完「项目设定」保存即可。
- **上传表格会影响方案吗？** 不会。表格只进达人库和投放数据。
- **换客户怎么办？** 在「全案策划」粘新 Brief 生成，项目设定自动切到新客户；旧的达人和投放数据不要了就在表里删除，或在「设置」重置。一个部署同一时间服务一个项目，多客户并行建议分开部署。
- **访客能改数据吗？** 不能。访客只能看和试用生成；导入、改状态、推送需要管理员口令登录。
- **数据存在哪？** 部署版存在服务端，所有人看到同一份；Claude 版和本地版存在各自浏览器里。
- **AI 生成的东西可信吗？** 文案和判断由 AI 生成，需人工审校；CPM、CPE、告警等数字是公式算的，可复核；KPI 是区间估算，不是承诺。
