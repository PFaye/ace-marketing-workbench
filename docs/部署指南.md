# ACE 营销工作台 · 部署指南

## 最短路径：3 步

1. **放到 GitHub。** github.com → New repository → 打开仓库页点「uploading an existing file」→ 把 `ace-workbench` 文件夹里的内容整个拖进去 → Commit。
2. **Zeabur 一键部署。** zeabur.com 登录 → New Project（区域选 Hong Kong）→ Add Service → GitHub → 选这个仓库。等它变绿，点 Networking → Generate Domain，得到网址。再点 Volumes → 挂到 `/app/data`（这样重新部署数据不丢）。
3. **打开网址。** 出现「初始化」：填一个口令、粘一个 DeepSeek Key（platform.deepseek.com 创建，充 10 元），点完成。结束。

不用填任何环境变量，不用命令行。之后访客打开网址就能看和试用；你点左下角「登录以编辑」改数据。

评委主要在国内的话，Zeabur 香港区域一般能直接打开；想更稳可以给 Zeabur 绑一个自己的域名。

## 在自己电脑上先跑一下（可选）

双击 `启动.command`（Mac）或 `启动.bat`（Windows）。首次会自动把 Node.js 下载到项目目录（不改系统），然后浏览器打开初始化向导。关掉窗口即停止。Mac 若提示“无法打开”，右键文件 → 打开。

## 其他部署方式

- **Railway / Render / 任何支持 Docker 的平台**：仓库里有 `Dockerfile`，连接仓库 → 挂持久卷到 `/app/data` → 部署。同样是打开网址走向导。
- **自己的服务器**：装 Node 18+，`node server/server.js`，默认 8787 端口；用 `pm2` 守护，Nginx 反代加 HTTPS。国内服务器用域名需备案，香港服务器不用。
- **不部署**：双击 `public/index.html` 也能用，数据存在浏览器里，模型在「设置 → 浏览器本地 API 设置」填。只是没有定时推送。

## 环境变量（可选，不填也行）

向导里设的口令和模型都存在数据目录；环境变量只在你更想用平台配置时才需要，且优先级更高。

| 变量 | 说明 |
|---|---|
| `ADMIN_TOKEN` | 管理员口令 |
| `LLM_BASE` / `LLM_KEY` / `LLM_MODEL` | 模型接口地址、Key、模型名（DeepSeek：`https://api.deepseek.com/v1` / `deepseek-chat`） |
| `LLM_KIND` | `openai`（默认）或 `anthropic` |
| `PORT` | 默认 8787 |
| `DATA_DIR` | 数据目录，Docker 里是 `/app/data` |
| `TZ_NAME` | 时区，默认 `Asia/Shanghai` |
| `PUBLIC_GENERATE` | `true`（默认）允许访客试用生成；`false` 必须登录 |
| `PUBLIC_DAILY_CAP` | 访客每日生成次数上限，默认 300 |

## 群机器人

- **飞书**：群设置 → 群机器人 → 添加「自定义机器人」→ 复制 Webhook；开了签名校验就把密钥一起填。
- **企业微信**：群设置 → 群机器人 → 添加 → 复制 Webhook。

填到「投放监测 → 自动推送」，点「发送测试消息」看群里有没有收到，再勾选自动运行与自动推送。

## 数据接入的现实边界

- 蒲公英没有公开 API，达人数据在后台导出表格后拖进「数据接入」即可，表头自动识别。
- 巨量引擎（含星图）、小红书聚光、腾讯广告的官方 API 需要企业资质和应用审核，连接器里留了凭证位置，拿到后按官方文档补拉取逻辑（`server/lib/connectors.js`）。
- 新榜、蝉妈妈等第三方数据服务的 API 用「HTTP 接口」连接器直接接。
- 不要用抓取类的“蒲公英接口”：不稳定且有法律风险。

## 常见问题

- 显示“服务端未配置模型”：在「设置」里填 Key，或向导时没填。
- 推送失败：先点“发送测试消息”看返回；飞书机器人若开了 IP 白名单要加服务器 IP。
- 重新部署后数据没了：没挂持久卷，挂到 `/app/data`。
- 想重置为示例数据：删除数据目录里的 `data.json` 后重启。
- 想改页面：改 `build/parts/`，然后 `python3 build/build.py`。
